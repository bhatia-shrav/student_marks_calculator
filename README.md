# Student Marks Calculator

A simple beginner-level Python project that calculates a student's total marks
and percentage across multiple subjects.

## Features

- Asks how many subjects the student has.
- Accepts marks between 0 and 100 for each subject.
- Checks that the entered values are valid.
- Calculates and displays total marks and percentage.

## Requirements

- Python 3

## How to run

1. Open a terminal in the project folder.
2. Run `python main.py` (or `python3 main.py` on some systems).

## Example

```text
=== Student Marks Calculator ===
Enter the number of subjects: 3
Enter marks for subject 1 (0-100): 85
Enter marks for subject 2 (0-100): 90
Enter marks for subject 3 (0-100): 80

=== Result ===
Total marks: 255 / 300
Percentage: 85.00%
```
